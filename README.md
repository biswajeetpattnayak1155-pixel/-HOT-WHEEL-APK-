# HOT WHEEL Android APK Project

This is an Android Studio project for the HOT WHEEL self-drive bikes & scooters app.

Features:
- Scooty: ₹60/hour, ₹400/12h, ₹600/24h
- Bike: ₹80/hour, ₹600/12h, ₹900/24h
- Customer booking form
- WhatsApp booking to 8249528073
- Direct call
- Real fleet photos
- Vehicle model subject to availability
- Bhubaneswar

Build locally in Android Studio:
1. Open this folder as a project.
2. Let Gradle sync.
3. Build > Build APK(s).
4. Debug APK will be under app/build/outputs/apk/debug/.

A GitHub Actions workflow is included at .github/workflows/build-apk.yml for cloud building after the project is pushed to a GitHub repository.
